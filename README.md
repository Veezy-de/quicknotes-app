# QuickNotes

QuickNotes is a simple note-taking web application that allows users to create, organise, search and delete notes. Notes can be assigned to Personal, Work or Study categories, and they are stored in the browser using localStorage so they remain available after refreshing the page.

## Features

- Create notes quickly
- Organise notes into Personal, Work and Study categories
- Delete individual notes
- Search notes by text
- Case-insensitive searching
- Validate empty notes
- Prevent notes longer than 200 characters
- Display the total number of notes
- Save notes using localStorage
- Restore notes after refreshing the page
- Responsive design for smaller screens
